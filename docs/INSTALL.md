# Installation / Установка

## Windows x64

Download one of the two public `v0.2.0` packages:

- [Installer (.exe)](https://github.com/zniks0n/Pulsar-Launcher/releases/download/v0.2.0/Pulsar-Launcher-0.2.0-x64.exe)
- [Portable (.zip)](https://github.com/zniks0n/Pulsar-Launcher/releases/download/v0.2.0/Pulsar-Launcher-0.2.0-x64.zip)

The release also includes a standalone portable `.exe` and `SHA256SUMS.txt`. Download the checksum file and the binary into one folder; on Linux/macOS run `sha256sum -c SHA256SUMS.txt`, or on Windows compare `Get-FileHash .\Pulsar-Launcher-0.2.0-x64.exe -Algorithm SHA256` against the matching entry. The builds are unsigned; Windows SmartScreen may report an unknown publisher. No signing certificate or publisher reputation is claimed.

The launcher installs and launches Java Edition Vanilla and Fabric instances. If the selected instance has no explicitly configured Java and the system Java is missing or too old, pressing Play downloads the official Mojang Java runtime matching that Minecraft version. Progress is shown and the download can be cancelled; the runtime path is stored for that instance. An explicitly selected Java executable is not silently replaced. Microsoft account sign-in is not included; offline profiles are for offline-mode servers, while supported Yggdrasil providers use the optional authlib-injector setting.

## Windows x64 — Русский

Скачайте один из двух публичных пакетов `v0.2.0`:

- [Установщик (.exe)](https://github.com/zniks0n/Pulsar-Launcher/releases/download/v0.2.0/Pulsar-Launcher-0.2.0-x64.exe)
- [Портативный архив (.zip)](https://github.com/zniks0n/Pulsar-Launcher/releases/download/v0.2.0/Pulsar-Launcher-0.2.0-x64.zip)

В релиз также входят отдельный портативный `.exe` и `SHA256SUMS.txt`. Скачайте файл хешей и бинарник в одну папку; в Linux/macOS выполните `sha256sum -c SHA256SUMS.txt`, либо в Windows сравните результат `Get-FileHash .\Pulsar-Launcher-0.2.0-x64.exe -Algorithm SHA256` с соответствующей строкой. Сборки не подписаны: SmartScreen может показать предупреждение о неизвестном издателе. Сертификат и подтверждённая репутация издателя не заявляются.

Лаунчер устанавливает и запускает Java Edition Vanilla и Fabric. Если для инстанса не задана собственная Java, а системная Java отсутствует или слишком старая, при нажатии «Играть» загружается официальная среда Mojang, подходящая к версии Minecraft. Показывается прогресс, загрузку можно отменить; путь хранится отдельно для инстанса. Явно выбранный Java executable не заменяется незаметно. Входа в аккаунт Microsoft нет; оффлайн-профили подходят только для серверов в offline-mode, а поддерживаемые провайдеры Yggdrasil используют необязательную настройку authlib-injector.
