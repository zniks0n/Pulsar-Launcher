# Installation / Установка

## Windows x64

Download one of the two public `v0.1.0` packages:

- [Installer (.exe)](https://github.com/zniks0n/Pulsar-Launcher/releases/download/v0.1.0/Pulsar-Launcher-0.1.0-x64.exe)
- [Portable (.zip)](https://github.com/zniks0n/Pulsar-Launcher/releases/download/v0.1.0/Pulsar-Launcher-0.1.0-x64.zip)

The release also includes a standalone portable `.exe` and `SHA256SUMS.txt`. Download the checksum file and the binary into one folder; on Linux/macOS run `sha256sum -c SHA256SUMS.txt`, or on Windows compare `Get-FileHash .\Pulsar-Launcher-0.1.0-x64.exe -Algorithm SHA256` against the matching entry. The builds are unsigned; Windows SmartScreen may report an unknown publisher. No signing certificate or publisher reputation is claimed.

The launcher installs and launches Java Edition Vanilla and Fabric instances. Java must be available on the computer; Pulsar checks the instance's Minecraft metadata and reports the minimum Java major version required before launch. For the smoke-tested Minecraft 1.21.4 case, Java 21 is required. An authenticated Microsoft account is not included in this early build; offline profiles are for offline-mode servers, while supported Yggdrasil providers use the optional authlib-injector setting.

## Windows x64 — Русский

Скачайте один из двух публичных пакетов `v0.1.0`:

- [Установщик (.exe)](https://github.com/zniks0n/Pulsar-Launcher/releases/download/v0.1.0/Pulsar-Launcher-0.1.0-x64.exe)
- [Портативный архив (.zip)](https://github.com/zniks0n/Pulsar-Launcher/releases/download/v0.1.0/Pulsar-Launcher-0.1.0-x64.zip)

В релиз также входят отдельный портативный `.exe` и `SHA256SUMS.txt`. Скачайте файл хешей и бинарник в одну папку; в Linux/macOS выполните `sha256sum -c SHA256SUMS.txt`, либо в Windows сравните результат `Get-FileHash .\Pulsar-Launcher-0.1.0-x64.exe -Algorithm SHA256` с соответствующей строкой. Сборки не подписаны: SmartScreen может показать предупреждение о неизвестном издателе. Сертификат и подтверждённая репутация издателя не заявляются.

Лаунчер устанавливает и запускает Java Edition Vanilla и Fabric. На компьютере должна быть Java; перед запуском Pulsar проверяет метаданные версии Minecraft и сообщает необходимую минимальную версию Java. Для проверенного сценария Minecraft 1.21.4 нужна Java 21. В ранней сборке нет входа Microsoft; оффлайн-профили подходят только для серверов в offline-mode, а поддерживаемые провайдеры Yggdrasil используют необязательную настройку authlib-injector.
