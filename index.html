AVAILABLE NOW · v0.2.0

A focused first release, built to work.

Pulsar ships as a Windows x64 launcher for Minecraft Java Edition. Here is what you can use today.

01

Java Edition

Create and launch Vanilla or Fabric instances. If compatible Java is missing, Pulsar can download the official matching runtime.

02

Instances & Modrinth

Keep installs separate, import compatible local or Prism folders, and manage compatible Modrinth mods with hash verification.

03

Accounts & diagnostics

Use offline profiles or a custom Yggdrasil server. Crash patterns are diagnosed locally; opening an external AI assistant is optional and user-initiated.

NOT INCLUDED IN v0.2.0

Microsoft sign-in, Bedrock, Forge/NeoForge/Quilt/OptiFine/LabyMod, CurseForge/FTB, Discord Rich Presence, automatic self-updates and broad launcher migration are not available yet.
