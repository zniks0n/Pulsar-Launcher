# Задачи Pulsar Launcher — сайт

## 1. Двуязычность и язык интерфейса
- Сайт поддерживает английский и русский языки.
- При первом посещении язык определяется автоматически по браузерной системной локали: русская локаль — русский, все остальные — английский.
- Пользователь может переключать EN/RU; выбранный язык сохраняется в `localStorage` и применяется при следующем посещении.

## 2. Hero и навигация по сайту
- Hero содержит логотип, описание Pulsar Launcher, кнопки «Скачать установщик (.exe)» и «Скачать портативную версию (.zip)», кнопку Discord и тёмный градиентный фон с частицами.
- Кнопки скачивания ведут на GitHub Releases, когда адрес релиза доступен; не выдавать незадействованные заглушки за реальные загрузки.
- Визуальный ориентир — XMCL: современный лаунчерный лендинг и выразительный интерфейс; не копировать бренд, тексты или фирменные графические материалы XMCL.
- Навигация по секциям сайта работает на настольных и мобильных экранах.

## 3. Возможности лаунчера
- На сайте есть карточки возможностей, включая ИИ-окно краш-репорта, Discord Rich Presence, импорт из других лаунчеров, автообновление и визуализатор прогресса.
- Карточки описывают заявленные функции продукта; не заявлять реализацию непроверенных функций лаунчера как готовую.

## 4. Скачивание
- Секция загрузок показывает два варианта: установщик `.exe` и портативная версия `.zip`.
- Для обоих вариантов предусмотрены размеры, даты и ссылки на GitHub Releases; неизвестные размеры, даты и ссылки не выдумывать.

## 5. Поддержка разработки и DONATE_URL
- На сайте есть отдельный блок «Поддержать разработку» и кнопка «Поддержать» с точным адресом `https://www.donationalerts.com/r/zn1kson`.
- Подвал также содержит кнопку поддержки с тем же адресом.
- В коде предусмотрена одна константа `DONATE_URL = "https://www.donationalerts.com/r/zn1kson"` для использования ссылок поддержки.

## 6. Об авторе и ссылки проекта
- На сайте есть блок «Об авторе» с именем Znikson.
- Ссылки автора используются как явные заглушки `[GITHUB_ZNIKSON]` и `[DISCORD_ZNIKSON]`, пока не заданы фактические адреса.
- В подвале есть ссылки Discord, GitHub, правила и политика, копирайт `© 2026 Znikson` и переключатель EN/RU.

## 7. Discord-секция
- На сайте есть Discord-секция с описанием, кнопкой приглашения и счётчиком участников.
- Приглашение использует заглушку `[DISCORD_ZNIKSON]`, пока не создан действительный сервер и не получена инвайт-ссылка.

## 8. Публичная поставка сайта
- Сайт адаптивен и содержит рабочие интерактивные состояния.
- Сайт собирается и публикуется на общедоступный URL; выдавать ссылку только после подтверждения успешной публикации.

## 9. Авторство и фактические внешние ресурсы
- Имя автора сайта и продукта — Znikson.
- Использовать ровно адрес DonationAlerts `https://www.donationalerts.com/r/zn1kson` для поддержки.
- Не подставлять выдуманные URL сайта, GitHub, Discord или релиза и не утверждать, что готовые бинарные файлы существуют без проверки.
